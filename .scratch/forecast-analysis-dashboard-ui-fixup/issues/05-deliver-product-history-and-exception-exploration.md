**Blocked by:** 03 — Deliver the single-source performance overview.

- [ ] The chronological history chart uses the available section width and preserves existing point and revision evidence.
- [ ] Point audit, consecutive revisions, and stability details are available through bounded expandable subsections.

- [ ] The default exception table emphasizes source, product, brand, target month, actual, latest forecast, absolute error, bias, revision outcome, and pair/mapping status.

- [ ] Existing product-history filtering, stability logic, exception ranking, visible-row behavior, and download fidelity pass regression tests.
